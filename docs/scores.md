# Transferability scores

The brainstorm report assigns one of these scores:

| Score | Meaning |
|-------|---------|
| **Low** | Only upstream/generic regulatory wiring transfers; all novel downstream claims fail or contradict |
| **Middle-Low** | Some downstream signal in specific conditions, but core mechanism doesn't hold broadly |
| **Middle-High** | Key downstream claims transfer with condition-specific strength; actionable leads present |
| **High** | Core mechanistic chain transfers broadly with strong statistical support |
