# Execute Agent Skill - Quick Reference

## Purpose
Run `Outputs/preprocess.R` first, then `Outputs/analysis.R`, capturing logs and
debugging common failures (msigdbr API, pathway-name mismatches, RAM crashes,
small typos). Save corrected scripts and a record of what changed.

## Files

| Type | Path |
|------|------|
| Input  | `Outputs/preprocess.R` (generated by code-agent) |
| Input  | `Outputs/analysis.R`   (generated by code-agent) |
| Reference (helper script) | `~/.claude/agents/Ref/Execute_Agent/references/pathway-helper.R` |
| Reference (debug rules)   | `~/.claude/agents/Ref/Execute_Agent/references/debug-rules.md` |
| Reference (RAM splits)    | `~/.claude/agents/Ref/Execute_Agent/references/ram-split-rules.md` |
| Output (logs)             | `Working/preprocess.log`, `Working/analysis.log` |
| Output (corrected scripts)| `Outputs/preprocess_corrected.R`, `Outputs/analysis_corrected.R` |
| Output (split scripts, if RAM crash) | `Outputs/analysis_corrected_part1.R`, `Outputs/analysis_corrected_part2.R` |
| Output (record)           | `Outputs/correction_record.txt` |

## Workflow

```
Run preprocess.R → preprocess.log
   ↓
   ├── clean? ─────────────────┐
   │                            │
   └── error? → diagnose → patch → save *_corrected.R → re-run
                                                            ↓
                                                       (up to 3 attempts)
   ↓
Run analysis.R → analysis.log
   ↓
   ├── clean? ─────────────────┐
   │                            │
   ├── RAM crash? → split → save part1.R, part2.R → re-run each
   │
   └── other error? → diagnose → patch → save *_corrected.R → re-run
                                                                  ↓
                                                             (up to 3 attempts)
   ↓
Write correction_record.txt
```

## Quick Rules

- **preprocess first, analysis second** — same order as the code agent's output.
- **Wait patiently for each Rscript to finish** — preprocess can take minutes, analysis can take an hour or more. A long silence is not a crash. Only judge PASS / FAIL after the command exits.
- **Always log** — use `Rscript ... 2>&1 | tee Working/<name>.log` (or equivalent) so the log captures both stdout and stderr.
- **First run uses the original files.** Only switch to `_corrected.R` after a fix is applied.
- **Do not edit the original `Outputs/preprocess.R` / `Outputs/analysis.R` in place.** All fixes go into `*_corrected.R` (or `_part1.R` / `_part2.R` for splits).
- **3-attempt cap per script.** If a script still fails after 3 corrections, stop and write a clear diagnosis to `correction_record.txt`.
- **Never split preprocess.R.** Only `analysis.R` may be split for RAM.

## The Four Bug Categories

| # | Category | Signal in log | Patch direction |
|---|----------|---------------|-----------------|
| 1 | msigdbr API | `Unknown subcollection` (typically from `"CP:KEGG"`) | Replace `"CP:KEGG"` → `"CP:KEGG_LEGACY"`. Leave `category` / `subcategory` alone unless they're actually failing — those are deprecated but still work. |
| 2 | Pathway name | msigdbr returns 0 genes; `AddModuleScore` empty | Source `pathway-helper.R`, call `get_pathway_genes(name, fallback_patterns=...)`, substitute the correct gs_name |
| 3 | RAM crash | `cannot allocate vector of size`, killed mid-task | Split analysis.R into part1 / part2 at the last successful task; patch the crashing task with rm/gc or summary-only loop |
| 4 | Other | Wrong column name, gene typo, `subset(... = X)`, missing dir | Local patch only; substitute the right name / fix syntax / add `dir.create()` |

See `debug-rules.md` for full diagnostic decision trees and
`ram-split-rules.md` for split-and-patch protocol.

## Pathway helper — usage

```r
source("~/.claude/agents/Ref/Execute_Agent/references/pathway-helper.R")

# Try the exact name first across all collections / subcollections:
get_pathway_genes("KEGG_GLYCOLYSIS")
# → [FAIL] No genes found for 'KEGG_GLYCOLYSIS'

# Provide fallback patterns to discover the real name:
get_pathway_genes("KEGG_GLYCOLYSIS", fallback_patterns = c("glycolysis", "glucose"))
# → prints candidate gs_names like KEGG_GLYCOLYSIS_GLUCONEOGENESIS,
#   HALLMARK_GLYCOLYSIS, REACTOME_GLYCOLYSIS, etc.
# → pick one and substitute into the script
```

## Critical Checks Before Declaring Success

- preprocess.log ends with `Preprocessing complete. Metadata written to Working/processed_meta.csv`?
- `Working/processed_meta.csv` exists and has > 0 rows?
- analysis.log ends with `========== ANALYSIS COMPLETE ==========`?
- `Outputs/plots/` contains the expected PDFs?
- `correction_record.txt` exists (even if it just says "no corrections needed")?
- For splits: BOTH part1 and part2 logs ended cleanly?
